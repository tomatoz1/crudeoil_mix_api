# crudeoil_mix_api

โปรแกรมคำนวณค่าเฉลี่ย API ของน้ำมัน 2–4 ถัง พร้อมหน้าต่าง Windows และโปรแกรมข้อความภาษาไทย/อังกฤษ

## เปิดใช้งานบน Windows

ใช้ Python 3.10 ขึ้นไปที่ติดตั้ง Tkinter (ตัวติดตั้ง Python สำหรับ Windows มีให้) ไม่ต้องติดตั้งแพ็กเกจเพิ่มเติม

ดับเบิลคลิก `Start-Oil-Mixer.pyw` หรือเปิดจากโฟลเดอร์โปรเจกต์:

```powershell
python -X utf8 api-mix/oil_gui.py
```

1. เลือกจำนวนถัง 2, 3 หรือ 4 ถัง
2. กรอกปริมาตรเป็น bbl และค่า API ให้ครบเฉพาะถังที่เปิดใช้งาน
3. กด **คำนวณ / Calculate** หรือ Enter เพื่อดูค่าเฉลี่ยและปริมาตรรวม
4. กด **ล้างค่า / Clear** เพื่อเริ่มใหม่ การแก้ข้อมูลจะล้างผลลัพธ์เก่าอัตโนมัติ

ปริมาตรต้องไม่ติดลบและผลรวมต้องมากกว่า 0 ค่า API ติดลบได้ แต่ทุกค่าต้องเป็นตัวเลขที่มีค่าจำกัด ระบบไม่บันทึกข้อมูลที่กรอกและไม่เชื่อมต่อเครือข่าย

## สูตรที่ใช้

คงวิธีประมาณค่าเดิมของโปรเจกต์: `sum(volume × API) / sum(volume)` โดยรวมปริมาตรทุกถังที่เลือก แก้บั๊กเดิมที่แบบ 3–4 ถังรวมตัวหารเพียงสองถัง

ตัวอย่าง: ปริมาตร 100 bbl ที่ API 20 และ 300 bbl ที่ API 40 ได้ค่าเฉลี่ย 35 และปริมาตรรวม 400 bbl

นี่เป็นค่าเฉลี่ย API แบบถ่วงปริมาตร ไม่ได้แปลง API เป็น Specific Gravity หรือชดเชยอุณหภูมิ จึงควรตรวจสอบวิธีคำนวณกับข้อกำหนดหน้างานก่อนใช้ตัดสินใจซื้อขายจริง

## โปรแกรมข้อความเดิม

```powershell
python -X utf8 api-mix/api-mix-th.py
python -X utf8 api-mix/api-mix-en.py
```

เลือกเมนู 1–3 เพื่อคำนวณ และ 4 เพื่อออก ทั้งสองภาษาใช้การคำนวณเดียวกับหน้าต่าง Windows

## ทดสอบ

```powershell
python -X utf8 -m unittest discover -s tests -v
```

ทดสอบสูตร การรวมปริมาตรครบทุกถัง การตรวจข้อมูล เมนูเดิม และปุ่ม/สถานะหน้าต่าง ต้องมีเดสก์ท็อปที่เปิดใช้งานได้สำหรับการทดสอบ GUI
